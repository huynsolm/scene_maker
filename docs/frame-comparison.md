# 미리보기 ↔ 실제 영상 자막 비교

측정일: 2026-10-27 · 기준: 1280×720 프레임에서 **미리보기 − 영상** (px, 양수 = 미리보기가 더 오른쪽/아래/큼)

## 요약
- **served** — 상자 위치 최대 33/1px(x/y), 크기 최대 66/1px(w/h) · 글자 경계 위치 최대 35/0px, 크기 최대 69/4px
- **noto** — 상자 위치 최대 2/1px(x/y), 크기 최대 4/1px(w/h) · 글자 경계 위치 최대 3/0px, 크기 최대 6/3px · 글꼴 로드 확인: true
- **pretendard** — 상자 위치 최대 31/1px(x/y), 크기 최대 62/1px(w/h) · 글자 경계 위치 최대 30/2px, 크기 최대 59/2px · 글꼴 로드 확인: true

- 상자 = 배경과 달라진 픽셀의 경계(반투명 어두운 박스). 글자 = 상자 안의 흰 글자 픽셀 경계.
- 미리보기 캡처는 화면상 위치를 반올림해 자르므로 **측정 오차가 약 ±1px** 있다. 1~2px 이하의 차이는 의미 있는 차이로 보지 않는다.
- 영상은 영상 파일의 중간 프레임(libx264 압축 후)을, 미리보기는 같은 크기로 키운 화면을 캡처해 같은 함수로 분석했다.
